# Movie Booking Analytics using MySQL

## Project Overview
This project analyzes movie booking data using MySQL to understand booking trends, revenue performance, customer behavior, and theatre utilization.

## Tools Used
- MySQL
- MySQL Workbench
- SQL

## Database Schema
The database contains four tables:
- `customers` — Customer details and signup information
- `movies` — Movie names, genres, languages, and durations
- `theatres` — Theatre details, cities, and seating capacity
- `bookings` — Booking details, show dates, seats, ticket amounts, booking status, and payment methods
